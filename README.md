# MAZORA RUN

Jogo arcade 2D em Pixel Art com movimentação de deslize contínuo em grade (estilo *Tomb of the Mask*), 20 fases matematicamente verificadas por BFS, 5 biomas, loja de personagens e áudio procedural via Web Audio API.

## Como Publicar no GitHub Pages
1. Extraia os arquivos na raiz do repositório `mazora-run` (`index.html`, `README.md`, `.gitignore`, `LICENSE`).
2. Faça commit e push na branch `main`:
   ```bash
   git add .
   git commit -m "Fix viewport canvas sizing v1.1"
   git push origin main
   ```
3. Acesse `https://allyxzs.github.io/mazora-run/` (pressione `Ctrl + Shift + R` para limpar o cache).
